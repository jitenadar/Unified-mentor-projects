Lexora — Legal Consultation Platform

A platform connecting clients with verified lawyers across multiple practice areas.

About

Lexora is my first internship project at Unified Mentor. It is a legal consultation platform where users can browse verified lawyers by specialization, check their ratings and fees, and book appointments directly through the platform.

Features

Search lawyers by practice area, location, and availability
Practice areas include Corporate Law, Criminal Defence, Family Law, Property, Taxation, and more
Lawyer profiles with ratings, experience, and consultation fees
Appointment booking with confirmation flow
Login and registration for clients
Fully responsive design for mobile and desktop


Built With

HTML5 — complete structure, styling, and interactivity written in a single file using vanilla CSS and JavaScript. Google Fonts (Playfair Display and DM Sans) used for typography.
